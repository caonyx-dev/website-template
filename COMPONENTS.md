# Component registry

What every template page is made of. Update this file whenever a template page is built or a component is added, renamed or removed. The source of truth for behaviour is the code; this is the map.

## Shared components (`src/components/`)

| Component | File | Kind | Content it takes | Motion / libraries |
|---|---|---|---|---|
| `Nav` | `Nav.tsx` | client | `brand`, `links`, `phone`, `phoneLabel`, `cta`, `menuExtra` (from `content.nav`) | Transparent over the hero, blurred solid bar after; hides on scroll down, returns on scroll up (GSAP ScrollTrigger). Full-screen `<dialog>` menu. |
| `Hero` | `Hero.tsx` | client | `image`, `eyebrow`, `lines[]`, `lead`, `actions`, `caption`, `scrollTo`, `stripe` (from `content.hero`) | Signature opening: curtain lifts, photo settles from 1.18 scale, headline lines rise through masks, then eyebrow, lead, buttons, caption fade up; photo parallax on scroll (GSAP). `next/image` with `priority`. `stripe` adds a 12px accent/dark hatch along the bottom edge (the builder's hazard band). |
| `Intro` | `sections/index.tsx` | server | `content.intro`: eyebrow, title, lead, three icon cards | Headline words rise (`Words`), cards stagger in (`RevealGroup`), cards lift on hover (CSS). |
| `DarkBand` | `sections/index.tsx` | server | `content.band`: eyebrow, title, four checks, text, cta, image, watermark | Primary-colour band with `Watermark`, `Words`, `RevealGroup` checks, `Reveal` image. |
| `Services` | `sections/index.tsx` | server | `content.services`: eyebrow, title, lead, image + note, numbered rows, stats | Image card with caption plate, rows fill accent on hover, stats stagger in. |
| `ModelBand` | `ModelBand.tsx` | client | `url`, `watermark`, `label`, optional `caption`, `title`, `steps[]` (label, title, text, facts) (from `content.model`) | The page's one 3D object as a scroll-driven walkthrough. With `steps`, the band is `steps × 100svh` tall and its frame pins (`sticky`) while the model turns; the chapter on the left switches with scroll progress (Motion `useScroll` + `useMotionValueEvent`), each re-entering with a CSS keyframe, under a chapter index and a facts list. Reduced motion: no pinning, chapters render as a list beside a sticky still model. Probes WebGL on mount, loads `MassingModel` with `next/dynamic` (no SSR), pauses the frame loop off-screen, tilts with the pointer; `Watermark` behind. Shows a one-line notice when WebGL is unavailable. |
| `MassingModel` | `MassingModel.tsx` | client | `url` of a `.glb` (preferred) or `.obj` under `public/models/<slug>/`, or `procedural:<name>` for an object built in code (`models/steelFrame.ts`); optional `mtl`, `materials` (`own` or `massing`); colours from the template tokens; `progress` MotionValue; `pointer` ref | React Three Fiber. Loads GLB with `useGLTF` or OBJ/MTL with the Three loaders, centres the model on a ground plate and scales it to 4 units. `materials: "own"` rebuilds each material from its name (concrete, plaster, sidewalk, aluminium, sandblasted metal, glass) with the maps in a `tex/` folder beside the model and a procedural room environment for reflections; `"massing"` renders plaster faces with ink `Edges`. Full size and fixed height throughout; only turns with scroll (`START_ROT`, `SWEEP_ROT`); one still frame under reduced motion. |
| `Process` | `sections/index.tsx` | server | `content.process`: eyebrow, title, lead, blueprint image, four steps, foot note + cta | Wraps `ProcessSteps`. |
| `ProcessSteps` | `ProcessSteps.tsx` | client | `steps[]` (n, title, text, image), `blueprint` | Staggered cards shift against each other on scroll and the blueprint drifts (GSAP); ghost numerals rise in (anime.js). |
| `Work` | `sections/index.tsx` | server | `content.work`: eyebrow, title, lead, three projects (tag, image, title, optional status and statusLabel, place, optional year, href), "all" link | Soft band, category pill on each photo, hover zoom (CSS), `RevealGroup`. Not used by any template at the moment (the architect has its own `WorkGallery`). |
| `Testimonial` | `sections/index.tsx` | server | `content.quote`: eyebrow, title, image, text, name, role | Image `Reveal`, headline `Words`, quote `Reveal`. |
| `Contact` | `sections/index.tsx` | server | `content.contact`: eyebrow, title, lead, include list, email, phone, partner, days | Dark rounded container; wraps `Enquiry`. |
| `Enquiry` | `Enquiry.tsx` | client | `partner`, `days`, `phone`, `copy` (labels, options, optional phone and preferred-start fields; defaults in `DEFAULT_ENQUIRY`) | Validated form (name, email, type, budget band, location, message, consent), inline errors, focus on first error, success state (anime.js). Posts nowhere yet. |
| `SiteFooter` | `sections/index.tsx` | server | `brand`, `content.footer`: blurb, address, columns, legal, credits | Static. |
| `SmoothScroll` | `SmoothScroll.tsx` | client | children | Lenis `ReactLenis root`, bridged to ScrollTrigger; off under reduced motion. |
| `Reveal`, `RevealGroup`, `Words` | `Reveal.tsx` | client | children, `from` (`up`, `left`, `right`, `scale`, `clip`), `delay`, `stagger` | Motion for React. Visible on the server; hidden only after mount when below the fold; shown on entry or after 3.5 s. `clip` wipes photographs up from the bottom. `RevealGroup` renders `div`/`ul`/`ol` and wraps each child as an item. `Words` splits strings and fragments into masked words. Elements already in view at load play their entrance after a short beat rather than skipping it. |
| `Parallax` | `Parallax.tsx` | client | children, `speed`, `rotate` | Moves and rotates its children with scroll (Motion `useScroll`), transform only, off under reduced motion. |
| `Magnetic` | `Magnetic.tsx` | client | a single control | The control leans towards the mouse pointer and springs back; ignores touch and reduced motion. |
| `BackToTop` | `BackToTop.tsx` | client | children | A `#top` link that appears once the hero has scrolled away. |
| `Letters` | `Letters.tsx` | server | `text`, `delay`, `step` | Splits text into letters that rise through a mask on load (CSS `rise-in`), used for wordmarks and hero names. |
| `Watermark` | `Watermark.tsx` | client | `text`, `onLight`, `center` | Giant ghost text that drifts sideways with scroll (Motion `useScroll`). |
| `Wrap`, `Eyebrow`, `Button`, `SectionHead`, `Accent` | `ui.tsx` | server | primitives | Container, pill eyebrow with accent dot, buttons (`accent`, `ink`, `ghost`, `ghost-dark`) whose corner, case and tracking come from the template tokens, section header (eyebrow + headline + lead, optional centred), accent-coloured span. |

Procedural models: `src/components/models/steelFrame.ts` (three-storey steel frame with slab, decking, bracing and an amber tower crane). Available through `url: "procedural:steel-frame"`; no template uses it at the moment.

Supporting modules: `src/lib/templates.ts` (reads `templates/*/DESIGN.md` into tokens), `src/lib/content.ts` (the `SiteContent` type), `src/app/globals.css` (maps `--t-*` tokens to Tailwind utilities), `src/app/[slug]/page.tsx` (style-sheet route for templates without a page), `src/app/page.tsx` (gallery).
