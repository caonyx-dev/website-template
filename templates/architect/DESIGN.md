## Overview

This is the design system for an architecture studio's website — a portfolio-led site whose job is to let the built work speak, then quietly route prospective clients (homeowners, developers, institutions), press and job applicants to the right next step. It reads like a well-hung gallery: a warm off-white `{colors.canvas}` floor, warm-charcoal `{colors.ink}` text, and a small family of warm greys that give every hairline, caption and disabled state its own deliberate step. Colour at page scale comes from the photography; the only chromatic mark the system itself makes is a single terracotta-rust `{colors.link}` — used for inline links, the active filter tab, and one horizontal accent rule per page. That rule is the entire decoration system.

Type is the second decisive voice. **Space Grotesk** carries display — hero statement, section heads, project titles — at weight 500 with gentle negative tracking, and weight 700 only for the smallest display step. **Inter** carries everything narrative: body, buttons, nav, captions. Captions and eyebrows are set as wide-tracked uppercase labels (`{typography.label-caps}`), echoing museum wall labels and drawing title blocks. Headlines are sentence-case; the system never shouts.

Surfaces use a four-step ladder: `{colors.canvas}` (the warm off-white page), `{colors.canvas-soft}` (a slightly deeper plaster tone for facts columns and process bands), `{colors.canvas-soft-2}` (an occasional inset region), and `{colors.primary}` (warm charcoal used as the polarity-flipped band for the studio statement or a drawing plate). There are no shadows anywhere in the system. Separation is achieved with whitespace first and 1 px warm hairlines second; cards are not boxes but regions of the grid.

**Key Characteristics:**
- A single warm-charcoal primary `{colors.primary}` carries every conversion target ("Start a project", "Enquire"), paired with an outlined `button-secondary` for the secondary action. Corners are 2 px — sharp, drafted, never pill-shaped.
- Terracotta `{colors.link}` is used sparingly: inline links, the active filter tab, the active index row, and one accent rule per page. It never fills a button.
- Every section eyebrow, caption and project tag uses `{typography.label-caps}` — 11 px, tracked +1.1 px, uppercase. Everything else is sentence-case.
- Zero elevation. No drop shadows, no stacked shadows, no glows. Hairlines and whitespace do all separation work.
- A warm material palette (`{colors.material-stone}`, `{colors.material-oak}`, `{colors.material-brick}`, `{colors.material-plaster}`) exists for diagrams, placeholder image plates and material swatches on project pages; it never appears on actions or text.
- The project index is a strict grid: 3-up (or 2-up for featured work) with consistent image ratios, caption under image, no borders, hairline rules between rows only.

## Colors

### Brand & Accent
- **Charcoal** (`{colors.primary}` — `#1C1C1A`): The single primary action colour and the text ink. Carries every "Start a project" button, the dark studio band, and the drawing plate. Warm (not blue-black) so it sits comfortably on the ivory canvas.
- **Terracotta** (`{colors.link}` — `#B45A2E`): The lone accent. Used for the active filter tab, the active index row rule, large-size text links, and one horizontal accent rule per page. Contrast on canvas is ~4.3:1, so it is reserved for emphasis at 16 px+ with weight 500, never for small running links.
- **Terracotta Deep** (`{colors.link-deep}` — `#94461F`): The small-text link tone (~6:1 on canvas) and the pressed state of any terracotta element. Use this for inline links inside paragraphs.
- **Terracotta Soft** (`{colors.link-bg-soft}` — `#F0DED2`): A pale clay tint for selected-state backgrounds in filters and for the notice bar when it carries a highlighted message.
- **Materials** (`{colors.material-stone}` `#A8A196`, `{colors.material-oak}` `#C9A57A`, `{colors.material-brick}` `#8E4F3A`, `{colors.material-plaster}` `#E9E3D8`): A subdued material swatch set for project-page specification diagrams, site plans and image placeholders. Decorative only.

### Surface
- **Canvas** (`{colors.canvas}` — `#F7F5F0`): The warm off-white page floor. Every section, card and dialog sits on this tone by default.
- **Canvas Soft** (`{colors.canvas-soft}` — `#EFEBE3`): The plaster tone — project facts columns, the process band, the enquiry form plate.
- **Canvas Soft 2** (`{colors.canvas-soft-2}` — `#E6E1D6`): A deeper inset for image placeholders, table headers and the selected row of a list.
- **Hairline** (`{colors.hairline}` — `#DDD6CA`): 1 px warm dividers — grid row rules, input borders, footer column rules.
- **Hairline Strong** (`{colors.hairline-strong}` — `#B9B2A4`): The stronger rule used under the nav and around inputs; also the de-emphasised icon tone.

### Text
- **Ink** (`{colors.ink}` — `#1C1C1A`): Every heading and body paragraph on light surfaces (~15:1 on canvas).
- **Body** (`{colors.body}` — `#4A4843`): Secondary text — project descriptions, nav-link inactive text, footer column body (~8:1).
- **Mute** (`{colors.mute}` — `#7D7A72`): Lowest-priority text — placeholder text, fine print, captions under images (~4.6:1 — the floor for text).
- **On Primary** (`{colors.on-primary}` — `#FFFFFF`): All text on `{colors.primary}` surfaces.

### Semantic
- **Success** (`{colors.success}` — `#4F6F52`): A muted sage for "enquiry sent" confirmations and completed-project status.
- **Error** (`{colors.error}` — `#A93F2E`): A brick red for form validation — deliberately close to the accent family so it does not jar.
- **Error Soft** (`{colors.error-soft}` — `#F2DAD3`): Soft clay fill for error-state field backgrounds.
- **Error Deep** (`{colors.error-deep}` — `#7E2E21`): Pressed / deep destructive state.
- **Warning** (`{colors.warning}` — `#B5862B`): Ochre for "in progress" / "planning" project status.
- **Warning Soft** (`{colors.warning-soft}` — `#F1E6CC`) / **Warning Deep** (`{colors.warning-deep}` — `#7A5A1B`): Background + pressed variants.

### Image Treatment
Photography replaces decoration, so the system defines three image treatments rather than a brand gradient:
- **Overlay** (`{colors.image-overlay-start}` → `{colors.image-overlay-end}`, charcoal at 0 % → 55 % alpha) — a bottom-weighted scrim on full-bleed hero images so a white title and caption remain legible.
- **Accent rule** (`{colors.rule-accent-start}` → `{colors.rule-accent-end}`) — the single 2 px terracotta rule, usually under the hero statement or above the footer. One per page.
- **Caption plate** (`{colors.caption-plate-start}` → `{colors.caption-plate-end}`) — the plaster gradient behind image placeholders while photography loads.

Treat photography as one unified object: full-bleed or on-grid, never framed in a rounded box, never with a drop shadow, never with a coloured tint. The work is in colour; the chrome is not.

## Typography

### Font Family
Two open faces carry the entire system:

1. **Space Grotesk** for display — hero statement, section heads, project titles and the small display step. Weight 500 is the only weight loaded; every display step, the wordmark included, is set in it. Display sizes are tracked slightly negative (`-1.2 px` at 48 px, `-0.64 px` at 32 px); the slightly quirky geometry of the face gives the studio its voice without needing colour.
2. **Inter** for everything else — body, buttons, nav, captions, tracked uppercase labels, and tabular figures in project facts. Weights 400 and 500 only. Tracking neutral for body; `+1.1 px` for `{typography.label-caps}`; `tnum` enabled for `{typography.facts-tabular}`.

There is no monospace role. Technical-looking labels (title blocks, facts, areas, years) are set in Inter with tabular figures instead — architectural, not software-like.

### Principles
- **Restraint over scale.** The hero statement is 48 px, not 80. Large imagery provides the scale; type stays measured.
- **Sentence-case headlines.** Only `{typography.label-caps}` is uppercase, and it is always small and tracked wide.
- **Labels are the technical layer.** Eyebrows, facts labels and image captions share one tracked-caps voice; body paragraphs never use it.
- **Weight 500 is the only display weight.** Nothing in the display face is bold; the system reads calmer because of this.
- **Figures are tabular.** Any column of numbers (areas, years, budgets) uses `{typography.facts-tabular}` so the facts column aligns like a title block.

### Note on Font Substitutes
Both faces are open-source and load from Google Fonts. If self-hosting is required, Space Grotesk and Inter are available under the SIL Open Font License. For a fallback-only rendering (no web fonts), `'Helvetica Neue', Arial` for display and `system-ui` for body preserve the proportions acceptably; keep the tracking values.

## Layout

### Spacing System
- **Base unit**: 4 px. Every captured value is a multiple of 4; the grid gutter is 24 px.
- **Tokens**: `{spacing.xxs}` 4 px · `{spacing.xs}` 8 px · `{spacing.sm}` 12 px · `{spacing.md}` 16 px · `{spacing.lg}` 24 px · `{spacing.xl}` 32 px · `{spacing.2xl}` 40 px · `{spacing.3xl}` 48 px · `{spacing.4xl}` 64 px · `{spacing.5xl}` 96 px · `{spacing.6xl}` 128 px · `{spacing.section}` 192 px.
- **Section padding**: bands use `{spacing.5xl}` to `{spacing.6xl}` top/bottom. The hero statement band stretches to `{spacing.section}` so the first image has room above it.
- **Card interior padding**: project cards have none (image flush to the grid cell, caption below with `{spacing.sm}` gap); text cards sit at `{spacing.xl}`.
- **Inline gap**: button rows, nav rows and filter-tab rows use `{spacing.md}` to `{spacing.lg}` between siblings.

### Grid & Container
- **Max width**: 1440 px for image grids; 1200 px for text-led pages (studio, process, journal). Content centres with horizontal gutters of `{spacing.xl}` 32 px on desktop, `{spacing.md}` 16 px on mobile.
- **Column patterns**:
  - Project index: 12-column grid; cards span 4 columns (3-up) by default, with a featured project spanning 8 columns at the top of the index.
  - Project detail: full-bleed hero image; then a 12-column body where narrative spans columns 1–7 and the facts column spans 9–12.
  - Filter-tab row: left-aligned row of `filter-tab` items under a hairline (All / Residential / Commercial / Public / Interiors).
  - Service cards: 3-up, hairline-topped, no fills.
  - People grid: 4-up portraits at 3:4, name in `{typography.display-sm}`, role in `{typography.label-caps}`.
  - Awards strip: a single hairline-ruled row of placeholder award names in `{typography.label-caps}`.

### Whitespace Philosophy
Photography does the heavy lifting; whitespace frames it. Section spacing is very generous — `{spacing.5xl}` to `{spacing.6xl}` between bands — and the index grid keeps a `{spacing.lg}` gutter so images read as separate works. Inside a card, the title/caption stack is tight (`{spacing.xs}` 8 px gap). The page reads as curated — large gaps between works, tight captions beneath them, never the other way around.

#### Collapsing Strategy
- **Nav**: wordmark left, link row centre (Work / Studio / Process / Journal / Contact), "Enquire" charcoal button right at desktop. Collapses to wordmark + "Menu" at mobile with the menu opening as a full-screen off-white overlay listing links in `{typography.display-md}`.

- **Full-bleed hero image**: 16:9 at desktop, 4:5 crop at mobile via `object-fit: cover` with the focal point set per image; the charcoal scrim sits at the bottom third.

- **Drawing plate**: a dark `{colors.primary}` rectangle holding a plan or section drawing rendered as light line-work; treated as an image at the layout level.
- **Portraits**: 3:4, black-and-white or consistently graded colour, no rounded corners.

## Elevation & Depth

| Level | Treatment | Use |
|---|---|---|
| Level 0 — Flat | No shadow, no border. | Everything by default: bands, project cards, images, the hero. |
| Level 1 — Hairline rule | 1 px `{colors.hairline}` top or bottom rule. | Service cards, index rows, footer columns, facts rows — the universal "this is a region" cue. |
| Level 2 — Strong rule | 1 px `{colors.hairline-strong}` rule. | Under the nav bar, around inputs, between the filter row and the grid. |
| Level 3 — Soft plate | `{colors.canvas-soft}` fill, no shadow. | Facts column, process band, enquiry form plate. |
| Level 4 — Dark plate | `{colors.primary}` fill, no shadow. | Studio statement band, drawing plate, facts-panel-dark, lightbox. |
| Level 5 — Overlay | Full-screen `{colors.canvas}` or `{colors.primary}` at 96 % alpha. | Mobile menu and the image lightbox. No shadow on the content inside. |

The system uses NO drop shadows at any level. Depth is communicated by tone (plaster vs. off-white vs. charcoal) and by rules. If a surface needs to "sit on" another, change its tone; never add a shadow.

### Decorative Depth
- **Photography as depth**: large images with real light in them are the only atmospheric element — the chrome never competes.
- **Polarity-flipped dark band as section-depth**: switching from `{colors.canvas}` to `{colors.primary}` for the studio statement or a drawing plate is the chief depth cue between bands.
- **The single accent rule**: a 2 px `{colors.link}` rule, used once per page, marks the most important moment — usually beneath the hero statement.

## Do's and Don'ts

### Do
- Reserve `{colors.primary}` (`#1C1C1A`) for primary CTAs and dark plates. Charcoal IS the conversion target; it is also the text ink, so buttons read as "text made solid".
- Use `{rounded.sm}` 2 px for every button and input and `{rounded.none}` for everything else. The system is drafted, not rounded.
- Set every headline in `{typography.display-*}` weight 500, sentence-case. Space Grotesk 700 appears only at `display-sm` and in the wordmark.
- Use terracotta `{colors.link}` sparingly — active filter, active row, one accent rule per page, large links. Use `{colors.link-deep}` for small inline links so contrast holds.
- Separate with whitespace first and hairlines second. If two regions need a boundary, add a 1 px `{colors.hairline}` rule, not a box.
- Cycle page surfaces in `{colors.canvas}` → `{colors.canvas-soft}` → `{colors.primary}` plates; the charcoal band IS the depth cue.
- Set every eyebrow, tag, caption label and facts label in `{typography.label-caps}`. Tracked caps are the voice of the title block.
- Let photography be full-bleed or flush to the grid, square-cornered, uncropped by chrome.

### Don't
- Don't introduce a second accent colour. The system operates with charcoal + warm greys + one terracotta; the material swatches are for diagrams only.
- Don't render headlines in all-caps. Caps belong to 11 px labels only.
- Don't add drop shadows of any kind — not on cards, not on the nav, not on dialogs. Tone and rules do the work.
- Don't fill a button with terracotta. The accent never becomes an action colour.
- Don't promote display to weight 700 above 20 px. The display ceiling at headline sizes is 500.
- Don't round images or place them in bordered frames. Square, flush, unframed.
- Don't fabricate awards, press names, client names or project facts; keep placeholders labelled as placeholders until the studio supplies them.
- Don't pack the index grid tighter than a `{spacing.lg}` gutter or more than 3-up; the works need room.

## Iteration Guide

1. Focus on ONE component at a time. Reference its YAML key directly (`{component.project-card}`, `{component.facts-panel-dark}`).
2. Variants of an existing component (`-sm`, `-feature`, `-dark`) live as separate entries in `components:`.
3. Use `{token.refs}` everywhere — never inline hex.
4. Never document hover. Default and Active/Pressed states only; the active filter tab and the current nav link are the only "state" visuals in the system.
5. Display stays Space Grotesk 500 with slight negative tracking. Body stays Inter 400/500. Labels stay tracked caps. The trinity does not blur.
6. The charcoal plate is scarce — one or two per page. Don't add other dark surfaces casually.
7. When in doubt about emphasis: more whitespace before more weight; bigger image before bigger type.

## Motion

Added 2026-10-07 at the owner's request; supersedes the earlier "no animation" stance in this file and PRODUCT.md principle 5 for this template. Motion is quiet, scroll-linked and drafting-flavoured: things settle, draw and fill; nothing bounces or glows.

- **Smooth scroll**: Lenis, lerp 0.1, anchors offset by the sticky nav.
- **Hero (signature moment, ~1.8s)**: a `{colors.primary}` curtain covers the photograph; a wireframe massing model of a gable house builds in over it (white edges, scaling from 0.55 and turning into place); the curtain wipes to the right with `clip-path` and the model's edges tween to `{colors.ink}` as the site photograph appears beneath it; the title block rises and the project name lands letter by letter through an overflow mask. Afterwards the model turns a further 1.1 rad as the hero scrolls, drifts up 20%, and tilts with the pointer; the photograph settles from scale 1.06 and drifts 8%. Model: faces `{colors.canvas-soft}` at 0.9, edges `{colors.ink}`, ground line `{colors.link}`; sits over the sky at top-left, 38% wide, 70% wide on phones.
- **Statement**: the headline's words rise into place once, 50ms apart, `cubic-bezier(.16,1,.3,1)`.
- **Work grid**: cards rise 24px and fade in, 80ms stagger, once, when the grid enters the viewport. Hover keeps the 1.03 image scale.
- **Dark band**: the section drawing is revealed left to right with a clip-path scrubbed to scroll, as if being drawn.
- **Process**: a 1px `{colors.link}` line fills down the stage numbers as the list is scrolled.
- **Recognition**: a single slow marquee (48s loop) with a Pause/Play control; paused on hover, focus and reduced motion.
- **Enquiry**: the success state fades and rises 12px.
- **Nav**: hides on scroll down past 200px, returns on scroll up.
- **Reduced motion**: all of the above is disabled; the page is static and complete.
- **Never**: `transition: all`, scroll hijacking, autoplaying video, more than one 3D object, glows or bouncing easings.
